# Dhanya Suresh Harikant — Portfolio

A responsive dark-futuristic, bento-inspired developer portfolio built with React, TypeScript, Vite, custom CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

- Replace `https://github.com/` with your actual GitHub profile URL.
- Replace `https://linkedin.com/` with your actual LinkedIn profile URL.
- Review project descriptions and add repository/demo links when available.
- Optionally add a resume PDF to `public/` and create a download link in `src/App.tsx`.
- Confirm the displayed education details and contact email.

The supplied resume did not contain project repository/demo URLs, so project cards intentionally do not invent links.
